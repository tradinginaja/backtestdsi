Screener Backtest Utility

Formula Mundur

Ubah kriteria screener menjadi versi mundur N hari bursa — otomatis menaikkan candle selector (prev, prev_2, dst) dan menghitung tanggal bursa yang sesuai, sesuai kaidah Data Saham Indonesia.

IDX · SENIN–JUMAT
libur & akhir pekan dilewati

1Formula Screener

Tulis kriteria seperti biasa. Atribut tanpa awalan dianggap "current" (hari berjalan) — tool akan menambahkan prev / prev_N secara otomatis saat dimundurkan.

2Tanggal & Rentang Mundur

Tanggal terbaru dianggap sebagai hari H (offset 0). Sabtu & Minggu otomatis dilewati.

Tampilkan seluruh rentang H sampai H-N (uncheck untuk hanya menampilkan H-N saja)

3Hari Libur Bursa (opsional)

Tambahkan tanggal merah / libur non-akhir-pekan yang perlu dilewati saat menghitung mundur, satu tanggal per baris, format DD/MM/YYYY. Kosongkan jika tidak ada.

4Simpan / Pulihkan Daftar Libur (File)

Unduh daftar hari libur di atas sebagai file .json di perangkat Anda. Lain kali ingin backtest dengan penyesuaian yang sama, tinggal unggah file itu lagi — atau kosongkan kolom libur untuk backtest tanpa penyesuaian tanpa perlu menghapus file backup-nya.
